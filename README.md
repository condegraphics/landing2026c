# Landing 2026 — Conde Graphics

OnePage HOME institucional para Conde Graphics, con eje en **SEO en la era de la inteligencia artificial**, y servicios complementarios de **SEM** y **Web**.

## Archivos principales

- `index.html`: estructura, copy, SEO semántico, JSON-LD y contactos.
- `styles.css`: sistema visual responsive en HTML/CSS moderno.
- `brand-spec.md`: paleta, tipografías, activos y decisiones de diseño.
- `img/`: logo y fotografías autorizadas por el usuario.
- `robots.txt` y `sitemap.xml`: base técnica para publicación.

## Sistema visual

La interfaz utiliza Merriweather Sans como familia única: peso 800 para títulos y peso 300 para los demás textos. La paleta se basa en azul día `#0073CB`, azul noche `#00215E`, negro, gris metal, gris luminoso, blanco y superficies azul pálido.

## Medición

GA4, Google Ads, Google Tag Manager y Meta quedan pendientes de activación. Esta versión no carga scripts de medición activos.

## Desarrollo local

Desde la carpeta del repositorio se puede levantar un servidor estático con cualquier servidor HTTP simple. Por ejemplo, con Python:

```bash
python3 -m http.server 8000
```

Luego abrir `http://localhost:8000`.
